# Paciente virtual: desarrollo de un simulador conversacional basado en inteligencia artificial generativa para el entrenamiento clínico y la evaluación de estudiantes de Medicina 
*Laura Sánchez Fernández - TFG para Ingeniería de la Salud* 

Tutores: Christian Cintrano López y Teodoro Rudolphi Solero 

Desarrollo de una aplicación web educativa basada en modelos de lenguaje (LLM) y técnicas de prompt engineering para simular entrevistas clínicas con pacientes virtuales. Orientada a estudiantes de medicina, permitirá practicar la anamnesis y recibir una evaluación formativa personalizada al finalizar cada simulación.

Para ejecutar: Escribir ".\iniciar.bat" en el símbolo del sistema de windows.
